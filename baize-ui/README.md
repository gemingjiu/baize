# baize-ui

白泽微服务框架 基于 Ant Design Pro 实现
## 环境准备

安装 `node_modules`:

```bash
npm install
```

## 提供的脚本

Baize 提供了一些有用的脚本来帮助你快速启动和构建 Web 项目、代码风格检查以及测试。 
`package.json` 中提供了这些脚本。修改或添加额外脚本是安全的。

### 项目启动

```bash
npm start
```

### 项目编译

```bash
npm run build
```

### 格式检查

```bash
npm run lint
```

你也可以使用脚本自动修复一些lint错误：

```bash
npm run lint:fix
```

### 代码测试

```bash
npm test
```
