# 白泽管理系统详细设计方案

## 一、项目概述

### 1.1 项目简介

白泽管理系统是基于 Spring Cloud Alibaba 的微服务架构后台管理系统，提供完善的用户、角色、菜单、权限等系统管理功能，支持多租户架构。

### 1.2 技术栈

| 类别 | 技术 |
|------|------|
| 微服务框架 | Spring Cloud Alibaba 2022.0.0.0 |
| 服务注册/配置 | Nacos 2.2.3 |
| 流量控制 | Sentinel |
| 负载均衡 | Spring Cloud Loadbalancer |
| 网关 | Spring Cloud Gateway |
| 安全认证 | Spring Security + JWT |
| 数据库 | MySQL 5.7 / PostgreSQL |
| 缓存 | Redis |
| ORM | MyBatis-Plus |
| 链路追踪 | SkyWalking |

### 2.1 baize-auth 认证服务

#### 2.1.1 功能概述

负责用户登录、登出、Token刷新、OAuth2第三方登录等认证功能。

#### 2.1.2 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/auth/login` | POST | 用户名密码登录 |
| `/auth/logout` | POST | 登出 |
| `/auth/refresh` | POST | 刷新Token |
| `/auth/userinfo` | GET | 获取当前用户信息 |
| `/auth/oauth2/success` | GET | OAuth2登录成功回调 |
| `/auth/oauth2/failure` | GET | OAuth2登录失败回调 |

#### 2.1.3 登录流程

```
用户输入用户名密码
       │
       ▼
验证租户是否存在且有效
       │
       ▼
查询用户信息（租户+用户名）
       │
       ▼
校验密码（BCrypt加密）
       │
       ▼
检查用户状态（是否启用、是否锁定）
       │
       ▼
生成JWT访问令牌（Access Token）
       │
       ▼
生成并保存刷新令牌到Redis
       │
       ▼
更新用户最后登录时间
       │
       ▼
返回Token和用户信息
```

#### 2.1.4 Token设计

**访问令牌（Access Token）**
- 有效期：2小时
- 存储内容：租户ID、用户ID、用户名、角色列表

**刷新令牌（Refresh Token）**
- 有效期：7天
- 存储位置：Redis
- Key格式：`refresh_token:{tenantId}:{userId}`

#### 2.1.6 核心实现

**AuthServiceImpl.java**
```java
public LoginVO login(LoginDTO dto) {
    // 1. 验证租户
    SysTenant tenant = validateTenant(dto.getTenantId());
    
    // 2. 验证用户
    SysUser user = validateUser(dto.getTenantId(), dto.getUsername());
    
    // 3. 校验密码
    passwordEncoder.matches(dto.getPassword(), user.getPassword());
    
    // 4. 生成令牌
    String accessToken = jwtUtils.generateToken(user, tenant);
    String refreshToken = UUID.randomUUID().toString();
    
    // 5. 保存刷新令牌到Redis
    tokenManager.saveRefreshToken(tenant.getId(), user.getId(), refreshToken);
    
    // 6. 更新最后登录时间
    userService.updateLastLoginTime(user.getId());
    
    // 7. 返回结果
    return buildLoginVO(user, tenant, accessToken, refreshToken);
}
```

**RedisTokenManager.java**
```java
public void saveRefreshToken(Long tenantId, Long userId, String refreshToken) {
    String key = String.format("refresh_token:%d:%d", tenantId, userId);
    redisTemplate.opsForValue().set(key, refreshToken, 7, TimeUnit.DAYS);
}

public boolean validateRefreshToken(Long tenantId, Long userId, String refreshToken) {
    String key = String.format("refresh_token:%d:%d", tenantId, userId);
    String storedToken = redisTemplate.opsForValue().get(key);
    return refreshToken.equals(storedToken);
}

public void deleteRefreshToken(Long tenantId, Long userId) {
    String key = String.format("refresh_token:%d:%d", tenantId, userId);
    redisTemplate.delete(key);
}
```

```java
public List<RouterVO> buildMenus(List<SysMenu> menus) {
    List<RouterVO> routers = new ArrayList<>();
    // 1. 获取所有目录和菜单
    List<SysMenu> menuList = menus.stream()
        .filter(m -> m.getMenuType() != 2)
        .collect(Collectors.toList());
    
    // 2. 构建树形结构
    Map<Long, List<SysMenu>> parentMap = menuList.stream()
        .collect(Collectors.groupingBy(SysMenu::getParentId));
    
    // 3. 递归构建路由
    for (SysMenu menu : menuList) {
        if (menu.getParentId() == 0) {
            RouterVO router = convertToRouter(menu);
            router.setChildren(buildChildren(menu.getId(), parentMap));
            routers.add(router);
        }
    }
    return routers;
}
```

### 4.3 AuthFilter

```java
@Component
public class AuthFilter implements GlobalFilter {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        // 1. 获取Token
        String token = getToken(exchange);
        
        // 2. 验证Token（跳过公开路径）
        if (!isPublicPath(exchange.getRequest().getURI().getPath())) {
            if (StringUtils.isEmpty(token)) {
                return unauthorized(exchange);
            }
            
            Claims claims = jwtUtils.parseToken(token);
            if (claims == null) {
                return unauthorized(exchange);
            }
            
            // 3. 传递用户信息到请求头
            ServerHttpRequest request = exchange.getRequest().mutate()
                .header("X-User-Id", claims.get("userId", String.class))
                .header("X-Tenant-Id", claims.get("tenantId", String.class))
                .header("X-Username", claims.get("username", String.class))
                .build();
            
            return chain.filter(exchange.mutate().request(request).build());
        }
        
        return chain.filter(exchange);
    }
}
```

## 七、安全设计

### 7.1 密码安全

- 使用BCrypt加密存储密码
- 密码强度校验
- 登录失败次数限制
- 定期强制修改密码

### 7.2 Token安全

- 访问令牌短期有效（2小时）
- 刷新令牌长期有效（7天）
- 登出后令牌加入黑名单
- 敏感操作二次验证

### 7.3 接口安全

- 请求频率限制（Sentinel）
- IP黑名单/白名单
- SQL注入防护
- XSS防护
