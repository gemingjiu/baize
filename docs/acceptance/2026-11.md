## 环境评估结论（2026-11-19）

在尝试执行 5 项 UI 走查前，先按 TASK_PLAN 要求评估运行环境，结论为**当前环境不具备端到端走查条件**：

| 依赖项 | 要求 | 实测 | 结论 |
| --- | --- | --- | --- |
| Nacos 注册/配置中心 | `localhost:8848`（默认值） | `curl http://localhost:8848/nacos/` → HTTP 000（不可达） | ❌ 未启动 / 无本地 Nacos 目录 |
| baize-auth 服务 | 8010 | 无监听 | ❌ 未启动 |
| 前端 dev server | 8000 / 3000 | 无监听 | ❌ 未启动 |
| Docker / Compose | 一键起栈备选 | `docker: command not found` | ❌ 不可用 |
| 远程 PostgreSQL | 192.168.5.4:30432 | `Test-NetConnection` → True | ✅ 可达 |
| 远程 Redis | 192.168.5.4:30379 | `Test-NetConnection` → True | ✅ 可达 |
| E2E 凭证 | `E2E_USERNAME` / `E2E_PASSWORD` / `E2E_TENANT` | 均未设置 | ❌ 未提供 |

**关键阻塞**：应用配置全部集中在 Nacos（`application.yml` 通过 `optional:nacos:` 导入 `application-dev.yml` 与 `baize-system-dev.yml`，其中含数据源、Redis、JWT 密钥、网关白名单等）。本地无 Nacos、无 Docker，虽远程 PG/Redis 可达，但缺配置中心导致后端服务无法启动，因此无法执行需要活服务栈的 UI 走查。
本机现存 2 个 java 进程经命令行核实均为 IntelliJ IDEA 的 SonarLint server 与 Maven server，**非 baize 服务进程**。

## 待运行环境就绪后执行的 5 项走查（TASK_PLAN T0.1）

1. **租户内置禁删**：内置租户/角色/字典删除按钮置灰，后端返回 `BUSINESS_CONFLICT`。
2. **字典驱动下拉**：下拉选项来自 `sys_dict` 接口，非硬编码。
3. **公告展示**：登录公告按租户/优先级显示，已读状态按 localStorage 记忆。
4. **岗位绑定**：用户-岗位设置可保存并回读（user_post 新主键链路）。
5. **租户切换**：UUIDv7 后切租户可用，nil UUID 平台租户正确识别。

每项需留存截图/接口日志证据；任一项失败 → 在缺陷档案新增条目并回对应提交排查，不进入 Wave 1「已交付」假设。
